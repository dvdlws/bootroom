# Free Cleats — Website

Website for a free youth soccer project in the San Gabriel Valley that is working toward nonprofit status. Do not describe it as a registered or tax-exempt nonprofit until that is true.

## Stack
Pure HTML/CSS — no framework, no build step. No other files needed.

## Deploy to Vercel
1. Push this repo to GitHub
2. Import repo at vercel.com
3. Deploy — zero configuration needed

## Deploy to GitHub Pages
1. Push to GitHub
2. Settings → Pages → Source: main branch / root
3. Site live at username.github.io/repo-name

## Connect Custom Domain (your domain)
1. Buy domain at Namecheap (~$15)
2. In Vercel: Project Settings → Domains → Add your domain
3. In Namecheap: Update DNS records to Vercel nameservers
4. Free SSL certificate automatic
